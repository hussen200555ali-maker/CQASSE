# معايير القبول (Acceptance Criteria)

## الدور: school_admin

| # | المعيار | ضروري للتسليم؟ |
|---|---------|:--------------:|
| 1 | يرى قائمة الفصول العامة (أسماء وتواريخ) | ✅ نعم |
| 2 | يرى إحصائيات مدرسته فقط (الشعب، التسجيلات، التقييمات) | ✅ نعم |
| 3 | لا يرى زر "تعيين الفصل الحالي" | ✅ نعم |
| 4 | لا يمكنه الوصول لـ `semester_setup.php` | ✅ نعم |
| 5 | لا يمكنه تغيير `lock_level` | ✅ نعم |

## الدور: group_admin

| # | المعيار | ضروري للتسليم؟ |
|---|---------|:--------------:|
| 1 | يرى قائمة الفصول العامة | ✅ نعم |
| 2 | يرى إحصائيات جميع المدارس (بدون فلتر) | ✅ نعم |
| 3 | يرى زر "تعيين الفصل الحالي" ويعمل | ✅ نعم |
| 4 | يمكنه الوصول لـ `semester_setup.php` وإدارة الفصول كاملة | ✅ نعم |
| 5 | يمكنه تغيير `lock_level` لجميع الفصول | ✅ نعم |
