# توثيق اختبارات النظام — EQAS

هذا المجلد يوثق عملية اختبار النظام ونتائجه، ويحتوي على:

| الملف | الغرض |
|-------|-------|
| `test-plan.md` | خطة الاختبار: استراتيجية، سيناريوهات، بيئة، أدوات |
| `test-results.md` | نتائج الاختبارات المنفذة مع لقطات الشاشة |
| `bug-log.md` | سجل الأخطاء المكتشفة والمصلحة |
| `acceptance-criteria.md` | معايير القبول لكل دور وميزة |
| `screenshots/` | لقطات شاشة مؤرشفة حسب التاريخ |

## كيفية استخدام هذا التوثيق

1. **للمطور:** راجع `test-plan.md` قبل البدء بالتطوير لفهم سيناريوهات الاختبار
2. **للمختبر:** سجل أي خطأ في `bug-log.md` مع خطوات إعادة الإنتاج
3. **لمدير المشروع:** راجع `acceptance-criteria.md` للتأكد من جاهزية التسليم
