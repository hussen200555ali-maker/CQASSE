# خطة اختبار النظام — EQAS v2.0.3

## 1. أهداف الاختبار
- التحقق من صحة المتطلبات الوظيفية (خاصة الصلاحيات وإدارة الفصول)
- ضمان عدم وجود ثغرات أمنية في التحكم بالوصول
- التأكد من استقرار النظام (عدم حدوث انتكاسات)

## 2. بيئة الاختبار

| المكون | الإصدار |
|--------|---------|
| نظام التشغيل | Windows |
| خادم الويب | Apache 2.4 (XAMPP) |
| PHP | 8.1.25 |
| قاعدة البيانات | MariaDB (MySQL) + SQLite (اختبارات) |
| المتصفح | Chromium |
| أداة الاختبار الآلي | PHPUnit 10.5 + Playwright 1.60 |

## 4. سيناريوهات الاختبار

### TS-01: تسجيل الدخول بأدوار مختلفة
| الحقل | القيمة |
|-------|--------|
| المعرف | TS-01 |
| خطوات الإعادة | زيارة `/login.php`، إدخال اسم المستخدم وكلمة المرور، النقر على "تسجيل الدخول" |
| النتيجة المتوقعة | يتم التوجيه إلى لوحة التحكم الخاصة بالدور |
| معيار القبول | `school_admin` ← `school_admin.php`، `group_admin` ← `admin.php` |
| آخر اختبار | ✅ PASS (يدوي) |

### TS-02: عرض الفصول الدراسية (school_admin)
| الحقل | القيمة |
|-------|--------|
| المعرف | TS-02 |
| خطوات الإعادة | تسجيل الدخول كـ `school_admin`، زيارة `/pages/academic/semesters.php?year_id=1` |
| النتيجة المتوقعة | رؤية جميع الفصول العامة مع إحصائيات مدرسته فقط |
| معيار القبول | تظهر الفصول في الجدول |
| آخر اختبار | ✅ PASS (تقارير) |

### TS-03: إخفاء زر "تعيين الفصل الحالي" عن school_admin
| الحقل | القيمة |
|-------|--------|
| المعرف | TS-03 |
| خطوات الإعادة | تسجيل الدخول كـ `school_admin`، فتح صفحة الفصول |
| النتيجة المتوقعة | لا يوجد `button[name="set_current"]` في الصفحة |
| معيار القبول | count = 0 |
| آخر اختبار | ✅ PASS |

### TS-04: حظر صفحة semester_setup.php عن school_admin
| الحقل | القيمة |
|-------|--------|
| المعرف | TS-04 |
| خطوات الإعادة | تسجيل الدخول كـ `school_admin`، زيارة `/pages/setup/semester_setup.php` |
| النتيجة المتوقعة | إعادة توجيه خارج الصفحة |
| معيار القبول | الـ URL النهائي لا يحتوي على `semester_setup.php` |
| آخر اختبار | ✅ PASS (اختبار الوصول) |

### TS-05: عرض الفصول الدراسية (group_admin)
| الحقل | القيمة |
|-------|--------|
| المعرف | TS-05 |

### TS-06: ظهور زر "تعيين الفصل الحالي" لـ group_admin
| الحقل | القيمة |

### TS-07: school_admin يدير معلمي مدرسته
| الحقل | القيمة |
|-------|--------|
| المعرف | TS-07 |

| معيار القبول | قائمة المعلمين ظاهرة + عدد الأزرار المناسبة |
| آخر اختبار | ✅ PASS (عزل المدرسة) |

### TS-08: school_admin يضيف معلماً جديداً
| الحقل | القيمة |
|-------|--------|

### TS-09: must_change_password — إجبار تغيير كلمة المرور
| الحقل | القيمة |
|-------|--------|
| المعرف | TS-09 |

| النتيجة المتوقعة | يتم تحويله إلى `change_password.php` إجبارياً |
| معيار القبول | URL يحتوي على `change_password.php` ثم بعد التغيير يذهب إلى dashboard |
| آخر اختبار | ✅ PASS (وحدة + تكامل) |
