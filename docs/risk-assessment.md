> التاريخ: 2026-05-20 · النطاق: كامل المستودع (بنية، أمن، تثبيت، تشغيل، بيانات، توثيق).

## 1. منهجية التقييم

- **الاحتمال (P):** 1 (نادر) — 5 (شبه مؤكد).
- **التأثير (I):** 1 (طفيف) — 5 (كارثي).
- **الخطورة = P × I** (1–25).

| النطاق | التصنيف |
|--------|---------|
| 20–25 | حرج (Critical) |
| 12–19 | مرتفع (High) |
| 6–11 | متوسط (Medium) |
| 1–5 | منخفض (Low) |

## 3. خط الأساس شبه-صفري (Defense-in-Depth)

لا يمكن الوصول إلى "مخاطرة صفر" مطلقة، لكن يمكن تقليص الخطورة المتبقية إلى **منخفضة + قابلة للرجوع** عبر 8 طبقات:

1. **فصل الأسرار:** لا أسرار في المستودع؛ الإعداد يُولَّد محلياً (`config.example.php` → `config.php`).
2. **تثبيت آمن:** محرّك موحّد + حراسة إعادة تشغيل + رفض القاعدة غير الفارغة + كلمة مرور إلزامية قوية.
3. **مرجعية البيانات:** فصل البيانات المرجعية (`seed.sql`) عن التجريبية (`sample_data.sql`) عن بيانات المستخدم.
4. **ترحيلات قابلة للتتبع:** مشغّل/سلسلة ترحيل idempotent + التحقق من تطابق `schema.sql`.
5. **الجودة الآلية:** PHPUnit (94/94) + Static lint + E2E لاحقاً، مربوط بـ CI.
6. **الأمان التشغيلي:** CSRF، bcrypt، تحديد محاولات الدخول، تجديد الجلسة، HTTPS إلزامي في الإنتاج.
7. **المرونة:** نسخ احتياطي مُختبر (يومي/قبل العمليات/يدوي) + إجراء استعادة موثّق ومجرّب.
8. **الرصد والتوثيق:** سجل أخطاء + توثيق المتطلبات (cron، صلاحيات، سياسة بيانات) + خطة استجابة للحوادث.
