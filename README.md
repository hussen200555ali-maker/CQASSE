## نظرة عامة
نظام متكامل لتقييم جودة التعليم المدرسي في الجمهورية ة، يهدف إلى توفير أدوات شاملة لتقييم وتحسين جودة العملية التعليمية من خلال مؤشرات كمية ونوعية مبنية على معايير علمية.

## المتطلبات التقنية
- **خادم الويب**: Apache (XAMPP)
- **PHP**: 7.4 أو أعلى
- **قاعدة البيانات**: MySQL 5.7+ / MariaDB 10.3+
- **الترميز**: UTF-8 (utf8mb4)
- **المتصفحات**: Chrome 80+, Firefox 75+, Edge 80+, Safari 13+

## التقنيات المستخدمة
- **الخلفية**: PHP (بدون أطر عمل)
- **قاعدة البيانات**: MySQL مع PDO
- **الواجهة**: HTML5, CSS3, JavaScript (vanilla)
- **الرسوم البيانية**: Chart.js 4.x
- **تصدير Excel**: EqasXlsxWriter (مكتبة مخصصة - ZIP + XML بدون تبعيات خارجية)
- **تصدير PDF**: TCPDF
- **الأمان**: CSRF, bcrypt, حماية القوة الغاشمة, تجديد الجلسات

## الأدوار الأربعة
| الدور | الوصف | الصلاحيات |
|-------|-------|-----------|
| مدير النظام (group_admin) | إدارة كاملة للنظام | جميع الصلاحيات + النسخ الاحتياطي + استعادة النظام |
| مدير المدرسة (school_admin) | إدارة المدرسة | إدارة طلاب/تسجيلات، تقييمات، إشراف، إعدادات، مخرجات |
| معلم (teacher) | التقييم والتدريس | تقييمات، درجات، حضور، سلوك، مهارات، تدريس |
| ولي الأمر (parent) | متابعة الأبناء | درجات، سلوك، حضور، مهارات، ترفيع، إقرارات، إشعارات |

## محرك التقييم الموحد
### 10 أدوات تقييم:
1. **مقياس ليكرت** (likert_5): 1-5 مستويات
2. **مقياس التكرار** (frequency_5): أبداً → دائماً
3. **مقياس الرضا** (satisfaction_5): غير راضٍ → راضٍ جداً
4. **نعم/لا** (yes_no): خيار ثنائي
5. **مقياس الشدة** (severity_4): عكسي! (4=لا يوجد → 1=شديد)
6. **عداد** (counter): رقم صحيح غير سالب
7. **رقمي 100** (numeric_100): 0-100
8. **رقمي مخصص** (numeric_custom): نطاق مخصص
9. **روبريك** (rubric_4): 4 مستويات
10. **نص حر** (text): بدون تسجيل درجة

### 7 أنواع تقييم:
1. التقييم السلوكي (behavior_eval)
2. قائمة المهارات (skills_checklist)
3. التقييم الذاتي للتدريس (teaching_self)
4. تقييم الأقران (teaching_peer)
5. التقييم الإشرافي (teaching_admin)
6. استبيان المناخ المدرسي (climate_survey)
7. فحص المرافق (facility_checklist)

## مؤشر جودة التعليم (EQI)
### الخوارزمية الهجينة:
- **50% تناسبي** + **50% متساوٍ** لإعادة توزيع أوزان الأبعاد المفقودة
- **6 أبعاد**: أكاديمي 35%، تدريس 25%، مناخ 15%، سلوك 10%، مهارات 10%، حضور 5%

## قرارات الترفيع (3 معايير إلزامية)
| المعيار | الحد الأدنى |
|---------|-------------|
| الأداء الأكاديمي | ≥ 50% |
| السلوك | ≥ 60% |
| الحضور | ≥ 75% |

- **مرفوع**: جميع المعايير مستوفاة
- **مشروط**: معيار واحد غير مستوفي (مع خطة تحسين)
- **معيد**: معياران أو أكثر غير مستوفاة
- **قيد المراجعة**: بيانات غير مكتملة

## النسخ الاحتياطي (3 مستويات)
1. **كامل**: يومي عند تسجيل دخول المدير
2. **قبل العملية**: قبل العمليات الحساسة
3. **يدوي**: تصدير مخصص من المستخدم

## التثبيت
1. نسخ المجلد إلى `htdocs/cqasse/` في XAMPP
2. إنشاء قاعدة بيانات `eqas_db` في phpMyAdmin
3. استيراد `database/schema.sql` ثم `database/seed.sql` ثم `database/settings_seed.sql`
4. تعديل `config.php` بإعدادات قاعدة البيانات
5. الوصول عبر `http://localhost/cqasse/`
6. أو استخدام معالج التثبيت `setup.php`
